OBJETIVO: Jogo da Forca Multilíngue com Integração de API e Níveis de Japonês.

1. INICIALIZAÇÃO:
   - Importar módulos (constantes, utils, api_engine).
   - Configurar dicionário de conversão Romaji -> Kana.

2. CONFIGURAÇÃO DO JOGO:
   - Limpar a tela e exibir boas-vindas.
   - Solicitar idioma (PT, EN, JP).
   - SE idioma for Japonês:
     - Solicitar dificuldade (A-Romaji, B-Sílaba, C-Kanji).

3. PREPARAÇÃO DE DADOS:
   - Tentar buscar palavra via API Online.
   - SE API falhar: Escolher palavra aleatória do dicionário local.
   - Definir PALAVRA_ALVO baseada no idioma/dificuldade:
     - PT/EN: Palavra normal.
     - JP Nível A: Leitura Romaji.
     - JP Nível B: Caracteres Kana (Hiragana/Katakana).
     - JP Nível C: Caractere Kanji único.

4. ESTADO INICIAL (VARIÁVEIS):
   - Chances = 6.
   - Lista de letras tentadas = Vazia.
   - Progresso (Underlines) = Quantidade de caracteres da PALAVRA_ALVO.
   - Dica Revelada = Falso (Verdadeiro se for JP Nível C).

5. LOOP PRINCIPAL (Enquanto houver chances e houver '_' no progresso):
   - Exibir Cabeçalho e Progresso.
   - SE Dica_Revelada: Exibir dica.
   - SENÃO: Oferecer dica por 2 chances (tecla '0').
   
   - RECEBER PALPITE:
     - SE JP Nível B: Converter entrada (ex: 'ka') para Kana (ex: 'か').
     - SE JP Nível C: Aceitar palavra completa em Romaji.
   
   - PROCESSAR PALPITE:
     - SE palpite == '0': Debitar 2 chances e revelar dica.
     - SE palpite já tentado: Avisar e repetir.
     - SE palpite está na PALAVRA_ALVO:
       - Revelar caracteres nas posições corretas.
     - SENÃO: Debitar 1 chance e adicionar às tentadas.

6. FINALIZAÇÃO:
   - SE não houver mais '_': Exibir mensagem de Vitória.
   - SENÃO: Exibir Game Over e revelar a palavra.
